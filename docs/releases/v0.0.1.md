# v0.0.1

Released: 2026-09-19

初回のパッケージ公開です。reranker の機能はまだ実装されていません。

- Python 3.11 以上に対応する `jev_reranker` パッケージの雛形を追加。
- uv による依存管理と、公開後1週間の cooldown を設定。
- pytest・ruff・ty・tox による開発用の検査を整備。
- GitHub Actions による検査、ビルド、PyPI Trusted Publishing を設定。
- wheel とソース配布物を PyPI および GitHub Release に公開。

[PyPI](https://pypi.org/project/jev-reranker/0.0.1/) · [GitHub Release](https://github.com/hotchpotch/jev-reranker/releases/tag/v0.0.1)
