# v0.0.1

Released: 2026-09-19

Initial package release. Reranking functionality is not implemented in this version.

- Add the `jev_reranker` package scaffold for Python 3.11 and newer.
- Configure dependency management with uv and a one-week release cooldown.
- Set up development checks with pytest, ruff, ty, and tox.
- Configure GitHub Actions for validation, builds, and PyPI Trusted Publishing.
- Publish the wheel and source distribution to PyPI and GitHub Releases.
